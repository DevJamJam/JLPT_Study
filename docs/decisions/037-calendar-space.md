# 큰 화면의 달력 공간과 내 기록 정렬 (#76)

이전 수정은 스크롤을 줄였지만 월간 날짜 칸을 64px 최소 크기로만 표시해 세로로 긴 화면에 큰 빈 영역을 남겼다. 패드·PC의 월간 콘텐츠를 남는 본문 높이에 맞추고 날짜 행이 공간을 나누도록 변경한다. 내용의 최소 높이는 유지하므로 모바일과 많은 멤버·짧은 화면에서는 필요한 스크롤을 유지한다.

달력 새로고침은 기존 Button과 react-icons의 새로고침 아이콘을 사용한다. 접근성 이름·툴팁·44px 조작 영역과 로딩 중 중복 요청 방지를 유지하고 상태 안내는 화면 읽기 도구로 제공한다.

내 기록에 남아 있던 760px 제한과 중복 상단 24px 여백을 제거한다. 공통 본문 960px와 공통 상단 24px 여백을 사용하며 카드 내부 패딩은 유지한다. 인증·기록 API·DB에는 변경이 없다.

큰 화면 높이 1266px에서 달력 아래 간격과 스크롤, 기존 화면 높이에서 전체 날짜 접근, 내 기록의 빈 상태와 긴 목록의 좌우 정렬을 화면 검사와 캡처로 검증한다. 실제 결과는 관련 PR에 기록한다.

초기 캡처 검토에서 1fr 행의 높이가 멤버가 많은 주를 기준으로 반복되어 불필요한 스크롤이 생기는 것을 발견했다. 행은 auto로 두어 각 주의 필요한 높이를 보존한 채 남는 공간만 나누며, 15명 표시에서도 패드·PC의 스크롤 없음 검사를 추가한다.
