# 선택 이모지의 컬러 표시

2026-10-07 · 이슈 #7

## 원인

검토 환경에 흑백 Noto Emoji를 설치했다. 해당 파일에는 색상 테이블이 없다. 컬러 Noto Color Emoji 설치 후에도 기존 Arial → 시스템 일반 글꼴의 대체 순서가 일부 고양이·원숭이 글자를 먼저 처리하여 흑백으로 남았다. CSS 색상 토큰은 막대·배경용이며 이모지 글자 자체의 색상을 정하지 않는다.

## 결정

시스템의 Apple Color Emoji / Segoe UI Emoji / Noto Color Emoji를 `Study Color Emoji`로 연결한다. 선택 가능한 20개 코드포인트에만 unicode-range를 적용하고 본문 글꼴 목록의 첫 순위에 둔다. 한글·숫자는 기존 글꼴을 유지한다. 이모지 문자와 파스텔 토큰 매핑은 변경하지 않는다. 이미지 이모지나 외부 CDN은 도입하지 않는다.

## 검증과 범위

Chromium의 실제 사용 폰트를 CDP로 조회하여 20개 모두 컬러 폰트로 렌더링되는지 검사한다. 375×667 / 820×1180 / 1280×900 화면의 설정 캡처를 남긴다. 검사 환경에는 컬러 Noto Color Emoji가 필요하다. Playwright의 Chromium 시스템 의존성 설치는 Ubuntu에서 fonts-noto-color-emoji를 포함한다. 별도 브라우저를 사용하는 환경도 컬러 폰트를 설치해야 한다.

운영체제별 이모지 모양은 유지한다. 세 시스템 컬러 폰트가 모두 없는 환경까지 컬러 표시를 보장하지 않는다. 실제 iPhone Safari·Windows 브라우저는 별도 기기 검증이 필요하다.
