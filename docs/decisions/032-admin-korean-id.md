# 관리자 아이디 ‘관리’와 운영 생성 차단 요인

사용자가 확정한 관리자 아이디는 `관리`다. 기존 초기화 명령은 영문·숫자 기반 3~64자만
허용해 해당 아이디를 거부했다. 완성형 한글·영문·숫자와 점·밑줄·하이픈으로 이루어진
2~64자를 허용하되 첫 글자 장식문자, 공백, 제어문자, 이모지는 거부한다.
기존 영문 아이디는 계속 지원한다. 비밀번호, singleton, scrypt 및 기존 계정 불변 처리는 유지한다.

현재 작업 실행 환경에는 운영 서버 키·초기 비밀번호가 없다. Vercel 환경변수를 저장하는
것만으로 이 명령이 실행되거나 이 작업 환경으로 전달되지 않는다. 비밀번호를 채팅·PR에
요청하거나 공개 생성 API를 추가하지 않는다. 운영자가 제어하는 비공개 환경에서 기존
명령을 실행해야 하며, 실행과 DB 조회가 확인되기 전 계정을 생성했다고 보고하지 않는다.

현재 관리자 로그인/API/화면은 아직 미구현이다. 과거 대화에서 이를 완료된 기능처럼
안내한 내용은 잘못이었다. 계정 생성과 관리자 기능 구현·검증을 구분한다.

후속 순서: 관리자 생성 → 관리자 로그인 구현·검증 → 일반 테스트 가입 → 실제 기록 저장·
새로고침·재로그인 조회 → 달력/스터디/내 기록 통계 → 종류 CRUD·팀원 내보내기·PIN 초기화 검증.
후속 진행은 Issue #64, 이번 아이디 수정과 생성 절차는 Issue #66에 기록한다.
화면 변경은 없으며 운영 관리자 생성은 아직 미실행이다. 검사 결과는 PR에 반영한다.
