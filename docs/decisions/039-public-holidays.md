# 한국 공휴일 자동 연동 (#80)

공휴일 처리가 없는 상태를 고정 안내 문구로 대신하고 있었다. 공공데이터포털 한국천문연구원 특일 정보의 getRestDeInfo를 서버에서 직접 조회한다. DATA_GO_KR_SERVICE_KEY에는 일반 인증키(Decoding)를 저장하며 URLSearchParams로 한 번만 인코딩한다. 클라이언트·응답·로그에 인증키나 원천 URL·오류 원문을 노출하지 않는다. 제3자 가공 데이터를 공식 데이터로 대체하지 않는다.

공휴일은 개인 정보가 아니므로 /api/holidays?year=YYYY는 공개 읽기 전용 API로 제공한다. 공부 기록·세션 API의 권한은 변경하지 않는다. 허용 연도는1999~서울 현재 연도+1, 요청은 year 하나로 제한한다. 연간 결과는 유효 날짜·이름·공휴일 여부·원천 성공 코드·페이지 수/항목 수를 검증하며, 연간 0건을 지원 여부가 불명확한 정상 데이터로 취급하지 않는다. 같은 날짜의 이름은 합치고 중복 이름은 제거한다.

현재 cacheComponents를 사용하지 않는 프로젝트이므로 Next 16.4.2의 호환 API unstable_cache로 검증한 연간 데이터만24시간 캐시한다. 오류를 던지면 정상 값으로 캐시하지 않고 기존 성공 값은 Next의 재검증 실패 정책으로 유지한다. 공개 응답은5분 캐시하며, 브라우저는1시간 간격/재접속/포커스/달력 새로고침 시 확인한다. 원천 반영과 캐시 주기에 따른 지연이 있으므로 실시간 갱신으로 표현하지 않는다. 최초 실패와 오래된 마지막 성공 데이터를 구분한다.

월간은 날짜 빨강과 이름, 주간과 상세는 공휴일 이름을 제공한다. 토요일보다 공휴일 빨강이 우선하고 일요일 빨강·일반 토요일 파랑을 유지한다. 달력 기간이 연도를 넘으면 두 연도를 조회한다. 공휴일 조회는 공부 기록과 분리하여 원천 실패가 기록 조회·입력을 막지 않는다. 미구현 고정 문구를 제거하고 실제 확인 중/실패/오래된 데이터 상태만 짧게 표시한다.

본인확인·활용신청 승인·인증키 확인은 사용자가 완료했다. 키는 채팅으로 받지 않고 Vercel 환경변수로 비공개 등록한다. 모의 검사와 실제 공식 API 조회를 구분하고, 운영 검증 전까지 Issue #80을 닫지 않는다. 검증 결과·캡처·실제 조회 상태는 PR에 기록한다.
