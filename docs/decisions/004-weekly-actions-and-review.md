# 주간 기록 버튼의 줄 배경 제거와 검증 전달 방식

2026-10-07 · 이슈 #11

## 원인과 누락

노트 줄 배경을 주간 카드 전체에 적용하고 기록 보기/추가 버튼을 투명하게 표시했다. 24px 줄 간격과 버튼 위치 검사는 통과했지만 글자 뒤로 줄이 지나가는 시각적 겹침을 놓쳤다. 간격 검사만으로 디자인 검수가 끝났다고 판단하지 않는다.

## 수정

노트 줄은 날짜 헤더·기록 본문에만 적용한다. 카드 전체에는 줄 배경을 두지 않는다. 버튼을 별도 weekActions 영역으로 분리하고 종이색 #FFFCFE 배경을 적용한다. 버튼과 본문 사이에는 24px 간격을 유지한다. 비활성 버튼의 opacity 때문에 줄이 비치지 않도록 부모 버튼 영역에도 줄 배경이 없다. 기록 진입 조건·본문 줄 높이·같은 행 버튼 위치는 유지한다.

## 실제 검증

모바일375×667 / 패드820×1180 / 컴퓨터1280×900 Chromium에서 버튼 영역·카드의 background-image가 none이고 버튼 영역 배경이 종이색인지 검사한다. 수정 화면 캡처에서 기록 보기·기록 추가·비활성 추가 글자 뒤로 줄이 지나가지 않는지 확인한다. 기존 입력·이모지·간격 검사를 함께 실행한다. 실제 기기 Safari는 별도 검증이다.

## 최신 협업 규칙

작업마다 블로그 HTML을 생성·전달하지 않는다. 커밋/PR·docs/decisions에 변경 근거와 실제 검증을 남긴다. 간격·정렬 등 화면 문제가 있을 때 캡처를 보여주고 검증한다. 블로그는 나중에 사용자가 요청할 때 이 기록을 근거로 별도 작성한다. 기존 공개 블로그와 이전에 전달한 HTML은 삭제하지 않는다. 검증 결과 전달 → 최신 PR 재검토 → CI 통과·특이사항 없음 확인 → 병합 순서를 유지한다. 이 규칙으로 이전의 커밋당 HTML 전달 규칙을 대체한다.
