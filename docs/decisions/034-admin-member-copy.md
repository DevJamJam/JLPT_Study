# 사용자 관리 안내 제거와 공부 종류 고유 ID 통일

사용자 요청으로 관리자 사용자 관리의 회원 수·정원 안내 문구를 제거한다.
가입 정원 제한과 회원 관리 동작은 변경하지 않는다.

기본 종류와 추가 종류 모두 기존 UUID `id`를 유일한 종류 식별자로 사용한다.
영어 입력·수정 기능은 추가하지 않고 불필요한 `seed_key` 컬럼을 후속 마이그레이션으로 제거한다.
이름 변경은 ID를 유지하며 기존 기록도 같은 종류의 현재 이름을 표시한다.
`name_key`는 이름 중복 검사에만 쓰는 정규화 값이며 영어 식별자가 아니다.

이미 적용한 최초 마이그레이션은 수정하지 않는다. 새 마이그레이션은 제한 시간 안에서
컬럼만 제거하고 CASCADE를 사용하지 않는다. 종류 행·UUID·기록 참조·이름·정렬은 보존한다.
격리 DB 테스트는 초기 fixture의 이름으로 ID를 조회하며 운영 식별자로 이름을 사용하지 않는다.
기본 종류·추가 종류 모두 기록이 있는 상태에서 이름 수정 후 동일 ID 참조를 검증한다.

Supabase CLI는 이 환경에 설치되지 않았고 앞선 npx 조회도 제한 시간에 종료됐다.
기존 저장소의 날짜/순번 파일 규칙으로 후속 SQL을 작성한다.
공식 데이터 삭제 문서에서 컬럼 제거 잠금과 lock_timeout 지침을 확인했다.
검증 결과·운영 적용·화면 캡처는 Issue #70과 PR #71에 구분해 기록한다.
