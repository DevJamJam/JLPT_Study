# 사용자 관리 정원 안내 제거와 종류 키 확인

사용자 요청으로 관리자 사용자 관리의 회원 수·정원 안내 문구를 제거한다.
가입 정원 제한과 회원 관리 동작은 변경하지 않는다.

`study_categories.seed_key`는 기본 데이터의 최초 등록 식별자다. 이름의 현재 영어 번역이 아니다.
기본 종류 이름을 바꿔도 유지되며 새 종류에는 할당하지 않는다. 운영 화면·API·통계는 이 키를
사용하지 않고 UUID `categoryId`로 종류와 기록을 연결한다. 따라서 이름 변경은 기존 기록에도
현재 이름으로 표시되며 영어 키로 인해 다른 종류로 연결되지는 않는다.

앞선 안내에서 영어 키를 현재 이름과 대응하는 저장 값처럼 설명한 것은 부정확했다.
종류별 영어 이름 관리 기능은 현재 요구사항이 아니므로 이번 변경에 추가하지 않는다.
초기 마이그레이션과 격리 DB 테스트의 고정 식별자 사용은 유지한다.

검증 결과와 화면 캡처는 Issue #70 및 해당 PR에 기록한다.
