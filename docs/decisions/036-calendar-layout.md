# 공통 너비와 달력 화면 높이 (#74)

홈은 960px, 상단과 하단은 1120px로 서로 다른 너비 기준을 사용했다. 공통 본문 내부와 상·하단을 960px로 통일하고 스크롤바 예약 공간도 같은 여백으로 반영한다. 스크롤 컨테이너와 콘텐츠 내부를 분리해 본문만 스크롤한다.

월간은 176px 장식 제목, 여러 줄의 조작부, 116px 날짜 칸이 누적됐다. 패드·PC에서 제목과 조작부를 가로로 배치하고 날짜 칸은 64px부터 내용에 맞게 늘어나도록 한다. 모바일은 기존 읽기 크기를 유지하고 공간이 부족하거나 멤버 표시가 많으면 기존 스크롤 안내를 유지한다. 월간 배경은 주간과 같은 라벤더 격자로 통일한다.

검증 결과는 PR #74 관련 변경 PR에 기록한다. 운영 DB와 API 계약은 변경하지 않는다.
