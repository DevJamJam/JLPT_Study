# 카카오톡 링크 공유 미리보기 (#90)

기존 배포에는 기본 title/description만 있고 대표 이미지와 OG 정보가 없었다. 루트 metadata에 공개 운영 URL·한국어 제목·소개·사이트명·1200×630 PNG를 지정한다. Twitter 큰 이미지 카드도 같은 이미지를 사용한다.

공유 이미지는 확정 분홍·라벤더 노트 색상의 코드 기반 SVG와 PNG다. 실제 회원·기록·계정 정보는 포함하지 않는다. 정적 PNG이므로 공유 크롤러가 로그인하거나 외부 이미지 생성 API·폰트를 호출할 필요가 없다. SVG는 편집 원본이며 배포에는 PNG를 사용한다. 이미지 본문은 서비스 영문 이름에 맞춰 영문으로, 카드 제목·소개는 한국어로 표시한다.

로컬 check/build 및 운영 비로그인 HTML의 OG 태그·이미지 HTTP 응답을 확인한다. 카카오톡 앱 내 실제 전송은 별도 확인이며, 기존 링크 캐시가 남으면 카카오 공식 OG 캐시 초기화 도구로 갱신할 수 있다. 검증 결과는 PR에 기록한다.
