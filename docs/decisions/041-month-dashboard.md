# 개인 월간 대시보드 (#84)

기존 내 기록은30건씩 목록만 제공해 확정 시안의 월 통계·종류별 막대가 빠져 있었다. GET /api/me/dashboard?month=YYYY-MM을 기존 일반 세션·그룹 검증 핸들러에 추가한다. 관리자는 공부 데이터에 접근하지 못한다. month만 한 번 허용하고 사용자·그룹은 세션에서 결정한다. 개인 데이터는 no-store이고 반환값은 월 요약·공개 종류 이름뿐이다.

기존 listRecords 기간 전체 조회와 listCategories의 페이지 처리를 재사용한다. DB 반환 상한보다 작은 페이지가 와도 빈 페이지까지 읽어 모두 합산한다. 별도 통계 테이블·RPC·DB 마이그레이션·의존성을 추가하지 않는다. 집계 기준은 studyDate이며 하루 여러 기록은 공부일 한 번, 최장은 하루 합계의 최댓값이다. 평균은 totalMinutes/studyDays를 분 단위 반올림한다. 기록이 없으면0이고 모든 등록 종류는0분 막대를 유지한다. UUID로 묶고 현재 종류 이름·정렬을 사용한다.

시안의 공통 Metric과 종류별 progress·이모지 색상 토큰을 재사용한다. 선택 월은 URL에 유지하고 새로고침 후에도 동일 월을 연다. 기존 월 이동 상한(현재 서울 월)을 유지한다. 목록은 날짜별 제목을 표시하고30건 더 보기와 통계는 독립이다. Query key는 records/user/group/dashboard/month로 기록 저장·수정·삭제 무효화에 함께 포함한다. 일반 오류는 기존 값을 유지하고 경고하며 새 월에는 이전 값을 보여주지 않는다. 통계나 목록의401·PIN변경·다른 계정·권한 오류는 양쪽 이전 데이터를 숨긴다.
