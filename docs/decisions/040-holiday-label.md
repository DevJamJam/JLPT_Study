# 공휴일 이름 가독성 (#82)

사용자 요청에 따라 공휴일 이름을12px·굵기700으로 통일한다. 월간·주간·상세가 같은 holidayName 스타일을 사용한다. 주간의24px 노트 행 높이와 좁은 날짜 칸의 줄바꿈을 유지한다. 화면 검사 데이터도 운영 응답의 긴 이름 대체공휴일(개천절)을 사용해 줄바꿈을 확인한다. 검증 결과와 캡처는 PR에 기록한다.

추가 사용자 피드백: 공휴일 줄 때문에 2열·7열의 합계·본문·버튼이 어긋났다. 같은 행의 날짜 카드가 날짜/공휴일/합계/본문/버튼의 다섯 행을 CSS subgrid로 공유하도록 한다. 공휴일이 없는 날짜도 빈 공휴일 행을 유지하며 긴 이름은 행 전체가 필요한 만큼 늘어난다.

1280px 이상에서는 공통 콘텐츠 폭을1200px까지 사용하며 상단·하단·홈·스터디도 같은 변수를 사용한다. 7열 주간은 남는 본문 높이에 맞추고 일반 글자를14px로 키운다. 공휴일 이름은 요청한12px·굵기700을 유지한다. 2열과7열의 합계/본문/버튼 위치를 비교하고1440×1266 캡처에서 폭·높이와 스크롤을 검사한다.

추가 좁은 화면 피드백: 768px 미만 날짜 칸에는 이모지를 쌓지 않고 참여 인원수만 표시한다. 날짜를 누르면 전원 상세를 확인한다. 768px 이상은 최대5명+N을 유지한다. 새로고침은 모든 화면에서 오른쪽 끝에 정렬하고 다음 기간 화살표와 오른쪽 좌표가 같은지 검사한다.
