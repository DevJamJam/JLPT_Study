# 독립 환경 인증 흐름 측정과 중복 작업 제거 (#44)

2026-10-26. 공개 무세션 GET의 결과를 로그인 처리 성능으로 확대하지 않고, 별도 GitHub runner에서 실제 임시 계정의 가입·로그인3회·me3회·이모지3회·PIN 변경·이전/새 세션 확인을 측정했다. 기준 run40258987354/job121366991414는 성공했다. API 실행 지역은hnd1이었다.

## 기준 측정

가입4060ms(app3095.5/db2146.5/DB요청9), 로그인1148/996/899ms(app751.7/821.1/730.9, 요청8), me292/248/246ms(요청3), 이모지205/198/195ms(요청1), PIN 변경1530ms(app1371/db208.4, 요청7). 전체 값은 네트워크 포함·소표본이고 첫 가입의 DB 연결/콜드 스타트 영향을 분리하지 못하므로 장기 평균으로 일반화하지 않는다.

## 개선과 보안 계약

- 실제 신규 가입(created=true): complete_join_result가 같은 그룹 잠금 안에서 신규 계정을 생성하고 user_credentials의 초기 버전은1이다. 방금 서버가 만든 scrypt 해시를 DB가 저장했으므로 같은 PIN을 다시 해시 검증하고 credential을 다시 읽는 작업을 제거한다. 최종 create_user_session에는 버전1을 전달해 잠금 아래 현재 버전·멤버십을 검사한다. 그사이 초기화/PIN 변경/삭제가 발생하면 발급이 거부된다. 기존 RPC의 현재 버전 검사를 제거하거나 결과를 캐시하지 않는다. 가입 재시도(created=false)는 현재 credential 재조회·PIN 재검증을 그대로 수행한다. 신규 가입의 DB 요청9→8, PIN 해시 계산2회→1회다.
- 로그인: users와 user_credentials의 기존 PK/FK 일대일 관계를 PostgREST embedded inner join으로 한 번에 읽는다. 새 테이블/권한/RPC는 없다. 중첩 행은 기존 자격증명 검증 함수를 공유하고 사용자 ID·해시·salt·고정 파라미터·버전을 검사한다. 잘못된 응답은503으로 닫고 두 번째 조회로 우회하지 않는다. 로그인 DB 요청8→7이다.
- 세션: resolve_user_session 검사가 먼저 끝난 뒤 같은 그룹에 대한 그룹·멤버 조회만 Promise.all로 실행한다. 멤버십·정원·DTO 검사를 그대로 수행한다. 총 요청 수3은 같지만 순차 대기 깊이는3→2다. 합산 db 지표는 병렬 실행 때문에 app보다 클 수 있다. 저장·인증 예약·PIN 확인을 병렬화하지 않는다.
- 시도 제한·Origin·보안 쿠키·고정 만료·버전 재검사·scrypt 비용·타임아웃은 유지한다. PIN·토큰을 로그/파일/GitHub secrets에 저장하지 않는다.

## 검사와 운영 측정

기존 검증에 신규 가입의 초기 버전1 발급/최종 버전 거부, 잘못된 중첩 credential 거부와 조회1회, 그룹 응답을 기다리지 않고 멤버 조회가 시작되는 의미 있는 gate 검사를 추가했다. 가입 재시도의 변경된 PIN 거부도 유지한다. 실제 실행 결과와 최종 CI/배포 후 같은 진단 job 재측정 결과는 PR에 기록한다. UI/CSS·DB 스키마는 변경하지 않는다.

측정 workflow는 같은 레포 PR에서 진단 파일이 바뀌거나 수동 실행한 경우에만 임시 계정을 만든다. 동시 실행은 직렬화한다. finally에서 수집한 세션을 모두 로그아웃하고, 정리용 가상 UUID/닉네임/requestId만 로그에 남긴다. 계정 삭제 권한을 GitHub에 주지 않아 계정은 담당자가 위3개 식별자를 대조해 별도 삭제해야 한다. 기준 측정 계정은 이미 정리했다. 성공 로그만으로 계정 삭제까지 완료됐다고 보고하지 않는다.

공식 근거: https://supabase.com/docs/guides/database/joins-and-nesting , https://docs.postgrest.org/en/v14/references/api/resource_embedding.html . Supabase 변경 이력도 확인했다. 운영 후 측정의 runner 위치/콜드 스타트·표본 수 차이는 결과의 한계로 함께 기록한다.
