# 기록 추가 정보 (#97)

필수 날짜·종류·시간만 기본 표시한다. 시작 시각·공부량/단위·메모는 네이티브 details/summary 추가 정보 입력 안에 유지하며 접어도 DOM을 제거하지 않아 FormData와 입력값이 보존된다. 기존 추가 정보가 있는 수정과 최신 기록 재조회는 자동으로 펼친다. 선택 필드 검증 오류가 있으면 펼치고 오류 필드에 초점을 옮긴다. 메모 placeholder는 예시를, 팝업 상단은 기록 전체 공개 안내를 담당한다. 키보드 토글·입력 유지·오류·필수만 저장과 기존 입력·수정·취소 동작을 검증한다.
