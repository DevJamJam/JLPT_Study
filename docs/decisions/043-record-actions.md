# 내 기록 정보·수정·삭제 같은 행 정렬 (#88)

수정·삭제가 기록 내용 아래 별도 줄의 텍스트 버튼으로 표시되어 소속과 조작 가능성이 불분명했다. 제목과 수정·삭제를 같은 flex 행에 배치하고 공통 Button secondary의 테두리·44px 높이를 사용한다. 버튼은 축소하지 않으며 긴 종류명은 제목 영역에서 줄바꿈한다. 메모·시작 시각·공부량은 그 아래에 유지한다. 날짜별 제목이 이미 있으므로 개별 기록 오른쪽의 중복 날짜는 제거하고 날짜 제목에 time 요소를 적용한다.

공통 버튼 스타일을 재정의하지 않는다. SE3 크기/패드/PC에서 긴 종류명과 버튼 중심·44px 높이·테두리·가로 넘침을 확인하고 기존 수정/삭제 동작도 회귀 검사한다. 실제 사용자 기록을 바꾸지 않고 가상 데이터 캡처를 제공한다. 실행 결과는 PR에 남긴다.
