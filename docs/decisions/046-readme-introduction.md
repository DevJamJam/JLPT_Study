# README 소개 페이지 정리 (#94)

같이달램 README의 배포 링크·화면·기술·폴더 구조 구성을 참고했다. 사용자·관리자 배포 링크를 구분하고 실제 앱 달력의 PC 검증 캡처를 포함한다. 상세 진행표·운영 설정·API 계약은 소개에서 제외하고 이전 README는 docs/archive/에 과거 보관본임을 표시해 보존한다.

기술 스택은 package.json과 현재 구현, 폴더 구조는 실제 디렉터리를 기준으로 작성한다. 공개 이미지에는 실제 회원·기록·비밀값을 포함하지 않는다. 검증용 예시 데이터임을 README에 명시한다. 이미지와 상대 경로·배포 링크 및 최종 확인 결과는 PR에 남긴다.
