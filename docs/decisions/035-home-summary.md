# 운영 홈 누락 수정

사용자가 가입 후 전달한 운영 화면에 확정 홈 대신 인증 확인용 환영 카드와 월별 기록 목록이
나타났다. SessionHome의 home/me 기본 분기가 RecordWorkspace를 공유하고 있었고 summary API가
없었다. 관리자 검증과 일반 홈 완성을 구분하지 못한 누락이다.

홈을 HomeWorkspace로 분리하고 기존 노트 시안의 인사·오늘/이번주 카드·기록 입력·오늘 상세·
오늘 참여자·최근 본인 기록을 실제 데이터에 연결한다. 인라인 로그아웃은 홈에서 제거하고
기존 내 설정 팝업을 사용한다. 월별 목록은 /me에 유지한다. 개인 월간 통계는 별도 미완료 범위다.

GET /api/summary는 기존 정상 사용자 세션·서버 전용 REST·no-store·시간 지표·오류 처리를
재사용한다. 요청의 임의 사용자/기간 조건은 받지 않는다. 서울 오늘·월요일·월초를 기준으로
본인 기간 기록과 같은 그룹의 오늘 기록만 최소 필드로 읽는다. 기존 멤버 검증·키셋 페이지 처리를
확장하므로 DB 반환 상한으로 합계가 잘리지 않는다. 최근 기록은 월 경계 없이 본인5개를
기존 정렬과 공개 DTO로 제한 조회한다. 새 테이블·마이그레이션은 없다.

요약에 userId/groupId를 포함해 브라우저가 다른 계정 응답을 거부한다. 실패는 0분으로 꾸미지
않고 —와 재시도 안내를 표시한다. 계정 만료/강제 PIN 변경 시 이전 요약을 숨긴다. 서울 날짜는
포커스·재연결·복귀·분 단위 확인으로 갱신한다. Query 캐시는 계정·그룹·날짜별 메모리에만 둔다.

공통 Button, Metric(기존 시안에서 승격), 노트 CSS 토큰, CalendarDetail, RecordForm,
RecordDelete, 입력 초안 history guard를 재사용한다. 달력의 RecordAction은 공용 기능 파일로
옮겨 홈·달력 모두 동일한 수정/삭제 조회·오류 처리를 쓴다. 직접 입력 성공은 홈으로,
상세에서 입력/수정 성공은 해당 날짜 상세로 돌아온다. 저장/수정/삭제 후 요약·상세를 갱신한다.

기존 월별 기록 검사는 /me에서 실행하고 인증 검사 로그아웃은 실제 설정 진입으로 변경한다.
검증 결과·SE3/pad/PC 캡처·운영 배포 및 실제 계정 확인 범위는 Issue #72와 PR에 기록한다.
