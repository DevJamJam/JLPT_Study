# 달력 참여자와 조작 버튼 통일 (#78)

기존 문서와 구현이 모바일3명·큰 화면11명으로 남아 있어 사용자가 요구한 최대5명과 달랐다. 모든 화면에서 가입순 최대5명만 렌더링하고 초과 인원은 +N으로 표시한다. CSS로 나머지를 숨기는 대신 DOM에서도 제외하며, 날짜 상세는 전원을 유지한다. CalendarParticipants를 실제 달력과 작동 시안에서 재사용하고 이전 숨김 클래스를 제거한다. 5/6/15명의 경계를 검증한다.

화살표는 44px 버튼·24px 아이콘이지만 새로고침은 20px 아이콘과 다른 테두리였다. 기존 공통 Button에 icon 변형을 추가하고 PeriodPicker와 새로고침에 적용한다. 버튼44px, 아이콘24px, 선2px, 테두리·배경·색·반경·중앙 정렬을 같은 CSS로 유지한다. 키보드 접근성과 비활성 처리는 그대로 유지한다.

검사와 캡처 결과는 관련 PR에 기록한다. DB·API·권한에는 변경이 없다.
