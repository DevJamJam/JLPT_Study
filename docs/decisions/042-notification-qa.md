# 운영 알림·입력 안내 점검 (#86)

운영 관리자 화면에서 PIN 초기화 확인창의 한국어 단어가 PC에서도 초/기화, 비밀/번호로 끊어졌다. SweetAlert2 기본 제목30px와 한국어 줄바꿈에 맡긴 것이 원인이었다. 공통 확인창 제목을22px/1.5, 본문16px/1.7과 keep-all·overflow-wrap:anywhere로 통일하고 버튼을44px 이상으로 맞춘다. 취소 우선 포커스와 파괴적 동작의 경고 색상은 유지한다. 토스트는 기존 성공 토큰과14px로 통일한다.

기록 필수값 누락은 HTML 기본 검증이 먼저 실행되어 영문 브라우저 말풍선이 나타났다. 이미 있는 UI/API 공통 검증을 사용하도록 noValidate를 지정하고 첫 오류 필드에 포커스한다. required·날짜/범위 등의 의미와 서버 검증은 유지한다. 자체 한국어 검증이 완비된 일반 로그인/가입·PIN 변경도 같은 방식으로 통일한다. 관리자 입력 폼은 별도 검증 구조이므로 이번 범위에서 기본 제약을 제거하지 않는다.

실제 일반 계정으로 로그인·점검 기록 저장·계속 작성 시 입력 보존·시간 수정·홈/달력/스터디/월 통계 반영을 확인한다. 사용자 실기기는 추후 유저 테스트 범위다. 계정/기록 영구 삭제와 PIN 변경은 운영에서 임의 실행하지 않으며 확인창·취소는 운영, 확정 변경의 전체 흐름은 격리 검사로 구분한다. 실제 사용자 데이터/스크린샷/자격증명은 저장소에 넣지 않는다. 최종 검사·캡처·한계는 PR과 #64에서 추적한다.
