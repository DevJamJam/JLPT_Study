001 · 빈 레포에 기준 커밋 만들기

2026-10-07 · 이슈 #1

문제와 이유

Git 브랜치는 커밋을 가리키는 이름이다. 파일과 커밋이 없는 새 레포에는 작업 브랜치를 만들 기준이 필요하다.

이번 변경

이 HTML 한 파일을 최초 기준 커밋으로 저장한다. 첫 초기화만 main에서 수행하고 이후 작업은 별도 브랜치에서 PR로 제안한다. develop은 생략한다.

검증

GitHub가 빈 레포임을 확인했고 이슈 #1 생성으로 쓰기 접근을 확인했다. 이 HTML의 파싱과 메타 태그를 검사했다. 앱이나 DB를 만들거나 테스트한 커밋은 아니다.

다음 작업

확정 설계·컬러 토큰·시안·협업 규칙·템플릿을 작업 브랜치에 추가한다. 해당 커밋에는 별도 기술 블로그 글을 포함한다. 실제 커밋 해시는 커밋 후 작업 보고에 연결한다.
